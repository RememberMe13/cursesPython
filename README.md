# Text based game in python

**Made with curses (Ncurses)**

## Requirements:

#### Unix
1. Curses should be installed by default with python on Unix systems.
2. To test:
```python
$ python
>>> import curses # No error
```


#### Windows
1. Install windows-curses using pip `pip install windows-curses`
2. Test like above.

## Usage:
1. cd into the cursesPython directory
2. Run main.py: `./main.py` or `python main.py`
3. Play game...
